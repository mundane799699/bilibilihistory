## 判断范围

实际原密码成功登录，排除了这次失败由该账号密码迁移损坏引起。新库正常建连及查询、低连接占用和无锁等待，也不支持“数据库停机、连接已满或分页 SQL 很慢”作为这次登录失败的原因。

目前故障定位在**新应用部署的数据库建连环节**。抓包更支持链路或部署差异，而非数据库内部认证查询失败；但没有读取腾讯云安全组实际规则，也没有取得故障 Function 的出口地址，不能断言具体是云安全组、运营商路由或 Vercel 出口故障。Vercel 默认出口 IP 是动态的，同一个区域的两个部署并不保证走同一条出口路径，这是待验证的方向。[Vercel 官方出口地址说明](https://vercel.com/kb/guide/how-to-allowlist-deployment-ip-address)
